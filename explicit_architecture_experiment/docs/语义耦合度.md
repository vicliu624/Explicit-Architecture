# ✅ 语义耦合度实验：技术规格说明（可直接用于 AI 编程）

## **一、实验目标**

构建一个可控的实验平台，用于测量**模块语义耦合度（Semantic Coupling）**对 AI 代码生成质量的影响。
平台需要自动构造不同耦合度的软件模块集合、生成提示（prompt）、调用 AI 模型生成代码，并分析生成结果的质量与预测损失。

---

## **二、核心思想**

语义耦合度指模块之间的语义依赖程度。
在 GPT 内部，对应 **Attention Density（注意力密度）**：

* 高耦合 → 注意力分散 → 模型预测困难
* 低耦合 → 注意力集中 → 模型更稳定

实验目标是：
**通过控制模块之间的依赖关系，观察生成正确率 / 预测损失如何变化。**

---

## **三、实验变量（Independent Variable）**

**模块耦合度等级：**

| 耦合度等级   | 描述                   |
| ------- | -------------------- |
| Level 0 | 完全独立模块，无跨模块引用        |
| Level 1 | 少量数据结构共享（例如共享一个 DTO） |
| Level 2 | 多处函数相互调用，但无逻辑循环依赖    |
| Level 3 | 存在逻辑循环依赖（A依赖B，B又依赖A） |
| Level 4 | 多模块交错依赖＋概念混淆（最难）     |

实验系统需要自动生成这些模块结构。

---

## **四、实验数据结构（AI 要生成）**

要求构建：

1. **模块节点结构**

```json
{
  "module_name": "UserModule",
  "functions": ["createUser", "deleteUser"],
  "data_types": ["User"],
  "dependencies": ["AuthModule"]
}
```

2. **模块依赖图（DAG 或循环图）**

```json
{
  "modules": [...],
  "edges": [
    ["UserModule", "AuthModule"],
    ["AuthModule", "LogModule"]
  ]
}
```

3. **Prompt 模板（根据耦合度自动生成）**

```
请根据给定的模块结构实现其中的函数。
模块依赖如下：
{{ dependency_graph }}

请编写 {{ target_module }} 的代码。
```

---

## **五、实验流程（AI 需实现的 Pipeline）**

程序需包含以下步骤：

### **Step 1：生成模块体系**

输入：耦合度等级（0~4）
输出：模块树 + 依赖图 JSON

算法要求：

* Level 0：随机生成3–5个彼此独立的模块
* Level 1–4：按规则增加依赖
* Level 3/4 必须包含循环依赖结构

---

### **Step 2：根据模块体系生成 Prompt**

* 使用模板自动填充模块函数、类型、依赖关系
* 模拟真实工程提示风格

---

### **Step 3：调用 AI 生成代码**

* 记录生成的代码
* AI 需在系统中预留接口，例如 `generate_code(prompt)`
* 不要求真实调用外部 OpenAI API，可模拟

---

### **Step 4：评估生成质量（Dependent Variables）**

系统需实现至少三类指标：

#### **1) 结构正确率（Structure Accuracy）**

检查生成代码是否严格包含需要的函数和类型。

#### **2) 依赖解析正确率（Dependency Resolution Accuracy）**

生成代码是否正确处理跨模块调用。

#### **3) 预测损失（Simulated LM Loss）模拟**

若无法获得真实模型 loss，用替代指标：

* Syntax error count
* Undefined symbol count
* 逻辑 inconsistency count

最终输出示例：

```json
{
  "semantic_coupling_level": 3,
  "code_correctness": 0.62,
  "dependency_accuracy": 0.41,
  "syntactic_error_count": 8
}
```

---

## **六、可复现性要求（AI 要做的）**

* 所有随机数需可以设定 seed
* 每个耦合度等级至少运行 30 次
* 自动生成统计图（均值 ± 方差）
* 输出最终报告：

包含：

* 不同耦合度 → 生成正确率曲线
* 不同耦合度 → 错误数量趋势
* AI 故障案例示例（Attention Drift 案例分析）

---

## **七、最终交付物（AI 应生成的代码组成）**

AI 在接到该说明后，必须输出：

1. `module_generator.py`

   * 自动构建不同耦合度的模块体系

2. `prompt_builder.py`

   * 根据模块体系生成提示

3. `experiment_runner.py`

   * 实现 30 次迭代
   * 收集指标
   * 输出 JSON 统计数据

4. `analysis.py`

   * 生成折线图
   * 汇总结果并解释趋势

5. `README.md`

   * 清晰描述如何运行实验

这一整套系统需要能 **一键运行**，得到一份完整实验报告。
